Hue support website — GitHub Pages setup

1. Replace every instance of REPLACE_WITH_SUPPORT_EMAIL in support.html and privacy.html with an email address you monitor.
2. Review the privacy policy carefully against your actual app and any SDKs; the current copy assumes an offline game without ads, analytics, or user accounts.
3. In the GitHub repository shanemcder.github.io, create a folder named hue and upload index.html, support.html, privacy.html, and styles.css into it.
4. Commit changes. If GitHub Pages is enabled, the URLs should become:
   https://shanemcder.github.io/hue/
   https://shanemcder.github.io/hue/support.html
   https://shanemcder.github.io/hue/privacy.html
5. Test both pages and the email links before submitting the URLs to App Store Connect.

This template is not a substitute for verifying Apple's privacy declarations and your app's actual data practices.
